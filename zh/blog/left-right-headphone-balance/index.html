iPhone左右声道平衡：耳机一边大一边小怎么办

EQfy团队 · 发布于 2026年10月11日 · 阅读约7分钟

要调整iPhone左右声道平衡，请打开“设置 › 无障碍 › 音频与视觉”（较早的iOS版本中为“辅助功能”），拖动“平衡”滑块；保持在中间，两只耳朵听到的声音就一样大。如果一只AirPod仍然比另一只响，请清洁扬声器网罩、检查佩戴是否贴合，并重置AirPods。如果无论换哪副耳机都是同一侧更小声，请咨询听力专业人士。

快速检查清单：一侧比另一侧小声

按顺序逐项检查，先从最快的开始。

  1. 在“设置 › 无障碍 › 音频与视觉”中，把“平衡”滑块调到中间。
  2. 播放两三首不同的歌曲，排除个别曲目混音不均的可能。
  3. 检查扬声器网罩上是否有耳垢或灰尘，并小心清洁。
  4. 重新戴好耳塞，或换一个尺寸的耳塞。
  5. 把AirPods放回充电盒30秒，必要时重置。
  6. 换一副耳机试试。如果仍是同一只耳朵更小声，请寻求专业帮助。

iPhone左右声道平衡怎么设置

“平衡”滑块是iOS内置的一项无障碍设置。它作用于整个系统，会影响所有App。以下步骤参考了Apple的iPhone使用手册：

  1. 打开设置App。
  2. 轻点无障碍，然后轻点音频与视觉。
  3. 向下滚动到平衡，向左或向右拖动滑块。
  4. 要让两侧恢复一致，把滑块拖回中间即可。

即使你不记得改过，也请检查一下这个滑块。它很容易被不小心碰到，而Apple针对AirPods音量不均给出的排查步骤中，也包括确认滑块位于中间。

何时打开单声道音频

在同一个屏幕上，你还能找到单声道音频。打开后，左右两侧会播放相同的内容，而不是各自独立的立体声声道。它在以下情况下很有用：

  • 你只戴一只耳塞听；
  • 你的一只耳朵听力比另一只好；
  • 歌曲把某些乐器完全放在一侧，这在一些老的立体声录音中很常见。

单声道音频能确保你的每只耳朵都听到完整的混音。但它不会让小声的耳塞变响，所以如果一侧偏弱，请继续排查下面的原因。

为什么一只AirPod比另一只声音大？

Apple关于左侧或右侧AirPod无法正常使用的支持文章，同时涵盖了无声和音量不均两种情况。以下是常见原因及对应的处理方法。

音频本身就不均衡

并不是每段录音都是平衡的。有些歌曲、播客和视频某一声道的内容更多，还有少数在混音或上传时就出了问题。如果只有某一首曲目或某个App听起来偏向一边，问题很可能出在内容上，而不是你的耳机。如果你在用EQfy - Louder Volume，也请确认它的耳机标签页已设为“中央”。

扬声器网罩上的耳垢或碎屑

网罩上薄薄一层耳垢或灰尘，就可能让一侧明显发闷。Apple建议取下耳塞，检查每只AirPod上的扬声器和麦克风网罩，并清除碎屑。请按照Apple的AirPods清洁指南中针对你所用机型的步骤操作，不要把尖锐物体戳进网罩，也不要用水冲洗AirPods。其他耳塞也是同样的道理：请查看制造商的清洁建议。

佩戴与耳塞

入耳式耳机依赖良好的密封。如果一侧戴得松，就会损失音量，尤其是低音，所以即使这只耳机本身没问题，听起来也会更小声。重新戴好耳塞，并试试其他尺寸；很多人左右耳需要不同尺寸的耳塞。

蓝牙或连接故障

有时只是一只耳塞失去了同步。把两只AirPods都放进充电盒30秒，在iPhone附近打开盒盖，确认两只都在充电。如果一侧仍有问题，就重置它们：在iPhone上前往“设置 › 蓝牙”，轻点AirPods旁边的“更多信息”按钮，再轻点“忽略此设备”，然后通过充电盒重置。具体重置步骤因机型而异，请参考Apple的AirPods重置指南。

有线耳机和转换器

使用有线耳机时，插头或转换器没有完全插好，可能导致某个声道消失或变弱。请重新插紧，检查iPhone接口里是否有棉絮；如果用了转换器，也换一个试试。如果移动线缆时某一侧出现噼啪声或断断续续，可能是线缆本身损坏了，任何软件设置都无法解决。

你的听力存在差异

如果硬件没有问题，可以做一个简单的对比。打开单声道音频，让两侧播放完全相同的声音，把“平衡”滑块调到中间，然后换一副耳机或另一台设备来听。如果每次都是同一只耳朵觉得更小声，差异可能出在你的听力上，而不是耳机。用一段左右声道测试音频（网上很容易找到）来对比会更快。

何时需要寻求专业帮助

平衡滑块可以抵消轻微、稳定的差异，但无法告诉你差异从何而来。出现以下情况时，请咨询医生或听力专业人士：

  • 一只耳朵的变化是突然出现的；
  • 伴有耳痛、耳鸣、闷堵感或头晕；
  • 清洁、重置并换用其他耳机后，一侧听起来仍然更小声。

不要靠调高音量来弥补听力较弱的那只耳朵，因为这也会提高另一只耳朵听到的音量。Apple也提供了一些可以与专业建议配合使用的听力功能：搭配支持的AirPods Pro，“健康”App可以进行听力测试（适用于成年人，并非在所有国家或地区都可用），并导出结果，与听力专业医护人员分享；“耳机调节”（位于同一个“音频与视觉”菜单中）可以在支持的Apple和Beats耳机上放大微弱的声音、增强某些频率。部分机型甚至可以用听力图来自定义它。

常见问题

iPhone的平衡设置在哪里？

前往“设置 › 无障碍 › 音频与视觉”（较早的iOS版本中为“辅助功能”），向下滚动到“平衡”。向左或向右拖动滑块；保持在中间，两只耳朵听到的声音就一样大。

为什么一只AirPod比另一只声音大？

常见原因包括扬声器网罩上有碎屑、“平衡”滑块不在中间、佩戴松动或连接故障。按照Apple的说明清洁网罩、检查滑块，然后把两只AirPods放回充电盒30秒，或者重置它们。

单声道音频能解决一只耳机声音小的问题吗？

单靠它不行。单声道音频会把相同的声音送到左右两侧，让你不会漏听歌曲的某些部分，但它无法让被堵住或有故障的耳塞变响。

EQfy的平衡滑块会改变整部iPhone的声音吗？

不会。它只改变在EQfy内播放的音频，不影响Spotify、YouTube、通话或系统声音。其他情况请使用iOS“设置”中的“平衡”滑块。

如果一只耳朵总是听起来更小声，需要看医生吗？

如果无论换哪副耳机差异都一样、差异是突然出现的，或者伴有疼痛或耳鸣，请咨询医生或听力专业人士。不要靠不断调高音量来弥补。
