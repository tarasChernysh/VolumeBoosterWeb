# EQfy - Louder Volume — website

Marketing site, blog and FAQ for the iOS app **EQfy - Louder Volume** (App Store: *Volume Booster Sound Amplifier*, id `6550912161`).
Live at **https://eqfy.app** (Cloudflare Pages project `louder-volume`). Plain static HTML — no framework, no `npm install`.

## Layout

```
index.html, es/ de/ tr/ zh/ da/index.html   Homepages (EN is the master; the others are generated from it)
blog/, faq/, <lang>/blog/, <lang>/faq/      GENERATED by build.mjs (en, es, de, tr, zh) — don't edit by hand
404.html, sitemap.xml, llms.txt             GENERATED by build.mjs
privacy.html, terms.html                    Legal pages (served at /privacy and /terms)
assets/css/site.css                         Styles for generated pages (homepages keep their inline CSS)
assets/images/                              Images; blog screenshots in assets/images/blog/
src/site.json                               Site settings (origin, App Store link, rating, languages)
src/i18n/<lang>.json                        UI strings for generated pages
src/content/<lang>/blog/<id>.html           Blog posts (JSON front-matter + HTML body)
src/content/<lang>/faq.json                 FAQ page content
src/landing/<lang>.json                     Homepage translations (EN string → translation)
src/landing-i18n.mjs                        Builds <lang>/index.html from index.html + src/landing/<lang>.json
src/og/*.html                               Templates for the 1200×630 share images
_headers                                    Cloudflare Pages headers (noindex for tooling paths, image caching)
tasks/                                      Notes: facts.md (app facts for writers), keyword-map.md, todo.md
```

## Everyday commands

```bash
node build.mjs     # regenerate blog, FAQ, 404, sitemap.xml, llms.txt and the "latest posts" block on homepages
node check.mjs     # validate links, canonicals, hreflang, headings, images, JSON-LD, sitemap (exit 1 on errors)
node indexnow.mjs  # AFTER deploying: notify Bing & other IndexNow engines (--since YYYY-MM-DD for changed pages, --dry-run to preview)
python3 -m http.server 8765   # preview at http://localhost:8765 (folder URLs work; /privacy needs the .html locally)
```

Deploy as before (from a clean checkout of `main`, after `node build.mjs && node check.mjs` pass), e.g.:

```bash
npx wrangler pages deploy . --project-name louder-volume
```

## Add or update a blog post

1. Read `tasks/facts.md` — it lists what the app really does and the claims we never make.
2. Create `src/content/en/blog/<id>.html`. The file name is the post id shared by all translations:
   ```
   ---
   { "slug": "my-post-slug", "title": "≤ 52 chars", "description": "140–160 chars", "keyword": "primary keyword",
     "category": "guide", "date": "2026-10-11", "updated": "2026-10-11",
     "image": "/assets/images/blog/iphone-duo/05-volume-booster.webp", "imageAlt": "…",
     "related": ["id-1", "id-2", "id-3"], "faq": [{ "q": "…", "a": "…" }] }
   ---
   <p class="lead">Direct answer…</p>
   <h2 id="section">…</h2>
   ```
   Internal links use placeholders so translations never hard-code slugs: `{{post:<id>}}`, `{{blog}}`, `{{faq}}`, `{{home}}`, `{{home}}#equalizer`, `{{appstore}}`.
   No `<h1>`, FAQ or download box in the body — the template adds them. Optional `"ogImage"` (PNG, 1200×630) and `"pinned": true`.
3. Translate it to `src/content/{es,de,tr,zh}/blog/<id>.html` (same id, localized `slug`, title, description, keyword, alts and FAQ).
4. `node build.mjs && node check.mjs`, preview, commit, deploy, then `node indexnow.mjs --since <today>`.

When something changes (e.g. iPhone Duo support ships in v2.2.23), edit the posts in every language, bump `"updated"`, rebuild.

## Update the homepages

Edit the English `index.html`, then for each language:

```bash
node src/landing-i18n.mjs extract de   # adds new/changed EN strings to src/landing/de.json with "" values
# translate the empty values (keep the {0}, {1} tokens — they stand for HTML tags)
node src/landing-i18n.mjs apply de     # writes de/index.html with identical markup
node build.mjs && node check.mjs       # check.mjs verifies every homepage has the same structure as index.html
```

Keep the App Store rating in `src/site.json` and the homepage JSON-LD (`aggregateRating`) in sync with the US App Store.

## Regenerating share images

```bash
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless=new --hide-scrollbars \
  --window-size=1200,630 --screenshot="$PWD/assets/images/og-image.png" "file://$PWD/src/og/site.html"
```
(Chrome may not exit by itself after writing the file — stop it once the PNG exists.)
